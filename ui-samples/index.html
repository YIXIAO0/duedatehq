DueDateHQ — UI direction samples

Same content (client detail page) rendered in different design directions. Click each to compare.

Original directions

  • A · QuickBooks Online style
    Banking-pro. Light blue accent, cool grays, dense table-feel rows. Most familiar to CPAs who use QBO daily.
  • B · Salesforce Lightning style (navy + sky · original)
    Enterprise. Navy + sky-blue, info-density per row, square-ish chrome, "screen of records" vibe.
  • C · Drake / Desktop pro-tool style (original)
    Most "old-school". Heavy borders, clear group boxes, almost-Windows feel. Densest and most pro-coded.

B · Theme variants — same SF Lightning structure, different palettes

  • B · Slate Graphite
    Cool slate neutrals + bright cyan accent. Linear / Stripe-y modern fintech feel.
  • B · Emerald CPA
    Classic accountant-trustworthy green on warm zinc. Fresh but not stale.
  • B · Plum Premium
    Distinctive violet on warm stone. Premium SaaS feel, stands out from QBO/Salesforce blue.
  • B · Burgundy Sophisticate
    Oxblood + warm cream. Old-money law-firm gravitas — for "trusted advisor" positioning.

C · Refined

  • C · Desktop pro-tool · refined
    Same density. Better typography (Inter + JetBrains Mono), softer hairlines, real depth, refined gradients on the chrome. Pro-tool that's actually nice to look at.

Open deadlines · list rendering — variants for the client-detail "Open deadlines" section

  • G · 4 layout variants on one page
    Polished bands · Date pills + cards · Timeline rail · Compact pro-tool. Same data in all four — pick by feel.
  • H · 5 timeline rail style variants
    Editorial minimal · Station markers · Changelog split · Floating cards · Pressure gradient. Five aesthetic takes on the same vertical-rail structure.

Client list — /clients page rendering

  • I · 4 client list layout variants
    Refined list · Compact data table · Card grid · Urgency-bucketed sections. Same 6 clients, four scan strategies — pick by book size and workflow.

New layout directions — responding to "list 不直观，要时间线 / to-do / 小日历"

  • D · Agenda + mini-calendar (Things 3 / Reminders.app feel)
    To-do list grouped by Today / Tomorrow / This Week / Next Week / Later. Mini-calendar in sidebar with deadline dots. Each item has a checkbox. Best for "what do I do right now."
  • E · Calendar-led (Fantastical / Outlook feel)
    Big month grid with deadline pills color-coded by category. Right sidebar shows selected-day detail + today's items + workload-by-week. Best for "see the month at a glance."
  • F · Timeline + action queue (Linear / Gantt feel)
    13-week horizontal timeline with one swim-lane per client. Markers for each deadline. "Today" indicator. Below: action queue for the next 14 days + pressure-point heatmap. Best for "spot the busy weeks."
