Timeline rail — 5 style variants

Same data, same vertical-rail structure, 5 different aesthetic treatments. All within the SF Lightning palette.

T1 · Editorial minimal

1px hairline rail, 8px solid dots, generous whitespace. Most restrained — reads like a New York Times timeline graphic. Zero chrome, all content. Best when this list is the focal element on the page.

My picks:

T1 if you want quiet and elegant — least chrome, most "content first".

T2 if you want the structural feel without going minimal — best baseline upgrade.

T3 if dates are the primary scan axis — best for "I know roughly when, find me what".

T4 if you want each date to feel like a separate event card — most "designed".

T5 if you want urgency to be a felt sensation — the gradient rail is the hook.

If forced to pick one: T2 (station markers) is the most balanced — quiet enough for everyday use, structured enough that it doesn't get lost when the list grows long. T5 is the most distinctive if you want this to be a signature element of the product.
